:::cena
Na primeira semana como genin, ninguém entende metade do que os jounin dizem. PC, Tenketsu, Hachimon, DT.

Este é o dicionário que eles esqueceram de entregar.
:::

Todas as abreviações, os termos em japonês e o jargão das regras, num lugar só, para consultar durante a sessão.

## Atributos {#atributos}

Os seis atributos do sistema.

| Abreviação | Nome | Significado |
| - | - | - |
| FOR | Força | Potência física: Taijutsu, armas corpo a corpo, escalar, carga |
| AGI | Agilidade | Velocidade e reflexos: Defesa, Iniciativa, armas à distância, furtividade |
| VIG | Vigor | Resistência corporal: PV, PE, resistir a venenos e à fadiga |
| INT | Inteligência | Raciocínio e estudo: investigação, medicina, selos |
| CTR | Controle | Precisão de chakra: Ninjutsu, Genjutsu, DT dos jutsus |
| ESP | Espírito | Vontade e percepção: PC, Percepção, Defesa Mental, resistir a Genjutsu |

| Abreviação | Significado |

## Termos Mecânicos {#termos-mecanicos}

| Termo | Significado |
| - | - |
| Rolagem padrão | 1d20 + perícia (ou atributo) + proficiência, contra a DT |
| Perícia | Valor total: atributo ligado + pontos de treino |
| Crítico | 20 natural no d20: sucesso espetacular; em ataques, os dados de dano dobram |
| Falha crítica | 1 natural no d20: o ataque erra; em testes, o Mestre narra uma complicação |
| Defesa | 10 + Acrobacia (o alvo de ataques físicos, de armas e de Ninjutsu) |
| Defesa Mental | 10 + Percepção (o alvo de ataques de Genjutsu) |
| DT do Jutsu | 10 + bônus de rank (E +0, D +1, C +2, B +3, A +4, S +5) + atributo-chave do lançador, mais a proficiência no jutsu, se houver |
| Resistência | Teste do alvo contra a DT de um efeito (por exemplo, 1d20 + VIG contra veneno) |
| Esquiva Ativa | Reação e 10 PE: 1d20 + Acrobacia substitui a Defesa contra um ataque |
| Iniciativa | 1d20 + AGI (define a ordem dos turnos em combate) |
| Ação Primária | Atacar, lançar jutsu, sprintar, comandar marionete em manobra completa |
| Ação Secundária | Mover (até 10 m), sacar item, comando simples a aliado |
| Ação Livre | Falar uma frase curta, soltar um item, efeitos descritos como livres |
| Reação | Ação fora do seu turno (1 por rodada) |
| Cena | Trecho contínuo de ação com o mesmo objetivo e no mesmo lugar |
| RD | Redução de Dano; fontes diferentes não se somam (vale a maior) |
| Fadiga | 5 níveis acumulativos: Cansado, Exausto, Esgotado, Colapso, Risco de morte |
