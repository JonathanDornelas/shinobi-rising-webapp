Esta seção reúne todas as abreviações, termos em japonês e jargões mecânicos usados no livro. Use-a como referência rápida durante a sessão.

## Atributos {#atributos}

Os seis atributos do sistema:

| Abreviação | Nome | Significado |
| - | - | - |
| FOR | Força | Potência física — Taijutsu, armas corpo a corpo, escalar, carga |
| AGI | Agilidade | Velocidade e reflexos — Defesa, Iniciativa, armas à distância, furtividade |
| VIG | Vigor | Resistência corporal — PV, PE, resistir a venenos e fadiga |
| INT | Inteligência | Raciocínio e estudo — investigação, medicina, selos |
| CTR | Controle | Precisão de chakra — Ninjutsu, Genjutsu, DT dos jutsus |
| ESP | Espírito | Vontade e percepção — PC, Percepção, Defesa Mental, resistir a Genjutsu |

## Recursos {#recursos}

| Abreviação | Significado |
| - | - |
| PV | Pontos de Vida |
| PC | Pontos de Chakra |
| PE | Pontos de Estamina (energia física — Taijutsu, Bukijutsu e Portões Internos) |

| PD | Pontos de Destino (re-rolagens e bônus dramáticos) |

| PJ | Pontos de Jutsu (criação de jutsus — cap. 20) |
| PFo | Pontos de Forja (criação de armas — cap. 21) |
| PB | Pontos de Bônus (criação de clãs — cap. 8.4) |
| PKG | Pontos de Kekkei Genkai (criação de KKGs — cap. 8.4) |

## Termos Mecânicos {#termos-mecanicos}

| Termo | Significado |
| - | - |
| Rolagem padrão | 1d20 + Perícia (ou Atributo) + Proficiência ≥ DT |
| Perícia | Valor total = atributo ligado + pontos de treino |
| Crítico | 20 natural no d20 — sucesso espetacular; em ataques, os dados de dano dobram |
| Falha crítica | 1 natural no d20 — o ataque erra; em testes, o Mestre narra uma complicação |
| Defesa | 10 + Acrobacia (alvo de ataques físicos, de armas e de Ninjutsu) |
| Defesa Mental | 10 + Percepção (alvo de ataques de Genjutsu) |
| DT do Jutsu | 10 + bônus de Rank (E0, D1, C2, B3, A4, S5) + atributo-chave do lançador |
| Resistência | Teste do alvo contra a DT de um efeito (ex.: 1d20 + VIG contra veneno) |
| Esquiva Ativa | Reação: 1d20 + Acrobacia substitui a Defesa contra um ataque |
| Iniciativa | 1d20 + AGI (define a ordem dos turnos em combate) |
| Ação Principal | Atacar, lançar jutsu, sprintar, comandar marionete em manobra completa |
| Ação Secundária | Mover (até 10 m), sacar item, comando simples a aliado |
| Ação Livre | Falar frase curta, soltar item, efeitos descritos como livres |
| Reação | Ação fora do seu turno (1 por rodada) |
| Cena | Trecho contínuo de ação com o mesmo objetivo e local |
| RD | Redução de Dano; fontes diferentes não se somam (vale a maior) |
| Fadiga | 5 níveis acumulativos: Cansado, Exausto, Esgotado, Colapso, Risco de morte |
