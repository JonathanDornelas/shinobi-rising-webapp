Se eu não consigo fazer do jeito normal, eu só preciso inventar um jeito que funcione para mim!
:::

Personagens podem desenvolver jutsus originais — desde técnicas singelas até obras-primas únicas. A criação é abstrata o suficiente para acomodar qualquer conceito que o jogador imagine, e simples o suficiente para que o equilíbrio se mantenha.

Todo jutsu — canônico ou criado — é descrito por três coisas no cabeçalho (Rank · Custo · Tipo) e SEIS atributos padronizados na linha de info. O resto (efeito, dano, condições) é texto livre que o sistema apenas precifica em pontos.

## 20.1 Anatomia de um Jutsu {#anatomia-de-um-jutsu}

Todo jutsu tem o mesmo esqueleto. Aprenda a ler a ficha antes de aprender a criar:

### Cabeçalho {#cabecalho}

- Nome + elemento associado se houver.
- Rank(E → S): mede o poder narrativo da técnica.
- Custo em PC ou PE: o que o personagem gasta para lançar (mais sobre PC vs PE abaixo).
- Tipo: a escola técnica do jutsu (Ninjutsu, Genjutsu, Taijutsu, Bukijutsu, Fuuinjutsu, Kugutsu).

### Linha de Info (6 atributos padronizados) {#linha-de-info-6-atributos-padronizados}

| Campo | O que define | Exemplos válidos |
| - | - | - |
| Alcance | Distância máxima de uso | Pessoal · Toque · Curto (10m) · Médio (30m) · Longo (60m) · Muito Distante (100m+) |
| Duração | Quanto dura ou custo de manutenção | Instantâneo · 3 turnos · 1 cena · Sustentado (X PC/turno) · Permanente (selo) |
| Área | Forma e escopo do efeito | Alvo único · Alvos adicionais · Cone 3m · Esfera 3m · Esfera 6m · Linha 10m |
| Ataque | Rolagem do usuário | 1d20 + Ninjutsu · 1d20 + Taijutsu · — (área) · Automático |
| Resistência | Como o alvo evita ou reduz o efeito | Acrobacia (DT do Jutsu) · FOR (DT do Jutsu) · ESP (DT do Jutsu) · — |
| Ação | Quanto custa do turno | Primária · Secundária · Reação · Completa (turno inteiro) |

### Corpo do Jutsu {#corpo-do-jutsu}

Logo abaixo da linha de info vem o EFEITO em prosa: o que o jutsu faz mecanicamente (dano, condição, cura, etc.) e uma descrição narrativa opcional. O efeito é texto livre — você descreve com palavras, e o sistema só verifica se o custo em pontos bate com a potência prometida.

## 20.2 PC vs PE — Que Custo Usar? {#pc-vs-pe-que-custo-usar}

Pontos de Chakra (PC) é o recurso espiritual usado pela maioria dos jutsus. Pontos de Estamina (PE) é um recurso paralelo — energia física— usado por técnicas marciais e de arma que não dependem de manipulação de chakra. A regra para escolher é simples:

| Tipo do Jutsu | Recurso | Lógica |
| - | - | - |
| Ninjutsu | PC | Manipula chakra para criar efeitos elementais ou energéticos |
| Genjutsu | PC | Manipula chakra para projetar ilusões na mente do alvo |
| Fuuinjutsu | PC | Selos e armadilhas que canalizam chakra para conter, marcar ou liberar energia |
| Taijutsu | PE | Técnicas corporais — exigem fôlego, músculo e treino, não chakra |
| Bukijutsu | PE | Técnicas com armas brancas — golpes precisos, kata, sequências marciais |
| Kugutsu | PC + PE | Marionete: PC para controlar (chakra fino), PE para movimentos rápidos do marionetista |

:::destaque{titulo="Quando o Custo é Misto"}
Alguns jutsus avançados combinam chakra e corpo. O custo é dividido: "5 PC + 3 PE" significa que ambos os recursos saem juntos no lançamento. Use isso para técnicas onde o ninja explicitamente queima corpo+chakra.
:::

## 20.3 Os Seis Tipos de Jutsu {#os-seis-tipos-de-jutsu}

O Tipo determina a escola técnica e a perícia usada na rolagem. Não é apenas tema — afeta quem pode aprender, copiar e se defender.

| Tipo | Perícia | Uso Típico |
| - | - | - |
| Ninjutsu | Ninjutsu | Jutsus elementais, clones, transformações, invocações |
| Genjutsu | Genjutsu | Ilusões mentais e controle de percepção |
| Taijutsu | Taijutsu | Combate corporal puro |
| Bukijutsu | Bukijutsu | Técnicas com armas brancas |
| Fuuinjutsu | Selamento | Uzumaki, Jiraiya, Anbu de elite. Selos, armadilhas, contenção, marcação |
| Kugutsu | Kugutsu | Sasori, Kankuro. Controle de marionetes com fios de chakra |

## 20.4 Criando seu Jutsu — 5 Passos {#criando-seu-jutsu-5-passos}

O sistema é abstrato: você compra componentes com Pontos de Jutsu (PJ), o total define o Rank, e o Rank determina o Custo final em PC ou PE.

### Passo 1 — Conceito + Tipo {#passo-1-conceito-tipo}

Defina em 1 frase: "lança de gelo que persegue o alvo", "chicote de água que afoga", "sequência de chutes giratórios". Escolha o Tipo do jutsu — isso determina se o custo será em PC ou PE.

### Passo 2 — Comprar Componentes com PJ {#passo-2-comprar-componentes-com-pj}

Cada elemento do jutsu custa Pontos de Jutsu (PJ). Some os PJ que comprar — a soma define o Rank e o custo final.

#### Dano e Cura {#dano-e-cura}

Para jutsus que causam dano direto ou curam aliados. Calcule o dano médio (d4 = 2,5; d6 = 3,5; d8 = 4,5; d10 = 5,5; d12 = 6,5; some os bônus fixos) e consulte a tabela. Cura usa a mesma tabela. Técnicas de Taijutsu e Bukijutsu somam o atributo ao dano sem custo de PJ (compensa o alcance corpo a corpo).

| Dano médio | Exemplos de dados | PJ |
| - | - | - |
| até 3,5 | 1d4, 1d6 | 1 |
| 4 a 5,5 | 1d8, 2d4, 1d6+1, 1d6+2 | 2 |
| 6 a 8 | 2d6, 2d6+1, 1d10+2 | 3 |
| 8,5 a 11 | 2d6+2, 2d8, 3d6, 2d10 | 5 |
| 11,5 a 15 | 3d8, 4d6, 2d10+4 | 7 |
| 15,5 a 20 | 3d10, 3d8+3, 5d6, 4d8 | 9 |
| 20,5 a 25 | 6d6, 4d10, 5d8 | 12 |
| 25,5 a 30 | 6d8, 5d10 | 15 |
| 30,5 a 40 | 7d8, 6d10, 8d8, 7d10 | 20 |
| 40,5 a 50 | 8d10, 9d10 | 25 |
| 50,5 a 60 | 10d10 | 30 |
| acima de 60 | +5 PJ a cada +10 de dano médio | +5 |

#### Alcance {#alcance}

| Categoria | Distância | PJ |
| - | - | - |
| Pessoal | Só você | 0 |
| Toque | Adjacente (até 1m) | 0 |
| Curto | Até 10m | 1 |
| Médio | Até 30m | 2 |
| Longo | Até 60m | 4 |
| Muito Distante | 100m ou mais | 8 |

#### Área {#area}

| Categoria | Escopo | PJ |
| - | - | - |
| Alvo único | 1 criatura ou objeto | 0 |
| Alvo adicional | Cada alvo extra (máx. +3); cada um tem sua própria rolagem ou Resistência | 2 |
| Linha 10m | Linha reta de 10m | 1 |
| Cone pequeno | Triângulo de 3m à sua frente | 1 |
| Esfera 3m | Tudo num círculo de 3m de raio | 2 |
| Cone médio / Linha 30m | Cone de 10m ou linha de 30m | 2 |
| Esfera 6m | Tudo num círculo de 6m de raio | 4 |
| Esfera 15m | Devastação localizada | 8 |
| Massiva (100m+) | Apenas Rank S — apaga terreno | 15+ |

#### Efeitos Especiais (condições no alvo) {#efeitos-especiais-condicoes-no-alvo}

| Efeito | PJ |
| - | - |
| Atordoa por 1 turno | 1 |
| Empurra ou derruba | 1 |
| Paralisa por 1 turno | 2 |
| Imobiliza (preso até vencer a Resistência) | 3 |
| Controla as ações do alvo (Resistência ao fim de cada turno) | 6 |
| Cega, ensurdece ou amedronta por 1 turno | 2 |
| Condição dura mais turnos (por turno extra, máx. +3) | +1 |
| Aplica veneno, queimadura ou sangramento contínuo | 2 |
| Sela chakra (o alvo não lança jutsus no próximo turno) | 2 |
| Drena chakra do alvo (1d6 PC; +1 PJ se transferir ao usuário) | 2 |
| Ignora cobertura ou RD | 2 |
| Persegue o alvo (acerto automático, salvo Esquiva Ativa ou Kawarimi) | 3 |
| Atravessa múltiplos alvos em linha | 3 |
| Cria barreira ou parede defensiva (a cada 10 PV) | 2 |
| Invocação ou clone autônomo | 4-8 |
| Sustentado: o efeito continua enquanto pagar ¼ do custo por turno (mín. 1) | 2 |

#### Efeitos em Si Mesmo ou em Aliado {#efeitos-em-si-mesmo-ou-em-aliado}

| Efeito | PJ |
| - | - |
| Buff em si mesmo: +1 em um atributo, ataque ou Defesa (3 turnos) | 2 |
| Buff em si mesmo: +2 em um atributo, ataque ou Defesa (3 turnos) | 4 |
| Buff dura 1 cena em vez de 3 turnos | +2 |
| RD 2 em si mesmo (3 turnos) | 3 |
| Cura aliado (mesma escala da tabela de dano) | = dano equivalente |
| Remove 1 condição negativa do aliado (paralisia, veneno) | 3 |
| Buff em aliado (+1 em atributo, ataque ou Defesa) por 3 turnos | 3 |
| Transferência de chakra (até 10 PC para aliado) | 4 |
| Concede uma ação secundária extra (uma vez) | 4 |

#### Modificadores no Custo Final {#modificadores-no-custo-final}

Ajustes que somam ou subtraem PJ no total. Use para dar sabor narrativo ou equilibrar potência:

| Modificador | Efeito no PJ |
| - | - |
| Requer condição rara (chuva, lua cheia, alvo enfraquecido) | -2 |
| Causa dano ao próprio usuário ao lançar (por 1d6; máx. -3) | -1 |
| Custa PV adicional no uso (a cada 5 PV) | -1 |
| Causa Fadiga ao usuário (por nível) | -1 |
| Exige outra técnica ativa ou portão aberto | -1 |
| Preparação de 1 turno completo (-1) ou de 3+ turnos (-2) | -1 / -2 |
| Não pode ser reusado na mesma cena | -2 |
| Componente material consumível (pergaminho específico, sangue) | -1 a -3 |
| Componente material durável (foco que precisa estar em mãos) | -1 |
| Sem selos (pode ser lançado com as mãos ocupadas) | +2 |
| Pode ser canalizado em arma (aplica o dano padrão da arma junto) | +3 |
| Combina 2 elementos (KKG) | +5 |
| Não pode ser copiado nem por Sharingan | +3 |

### Passo 3 — Verificar o Rank {#passo-3-verificar-o-rank}

Some todos os PJ comprados e ajuste com modificadores. O total define o Rank:

| Soma de PJ | Rank Final | PT para aprender |
| - | - | - |
| 1-2 | E | 1 PT |
| 3-5 | D | 2 PT |
| 6-10 | C | 4 PT |
| 11-18 | B | 8 PT |
| 19-30 | A | 15 PT |
| 31+ | S | 30 PT |

### Passo 4 — Custo Final em PC ou PE {#passo-4-custo-final-em-pc-ou-pe}

O custo final em PC (ou PE, para Taijutsu e Bukijutsu) é igual ao total de PJ:

Custo Final = PJ (mínimo 1). Efeitos sustentados custam ¼ do custo por turno, arredondado para cima.

### Passo 5 — Os 6 Atributos Padronizados {#passo-5-os-6-atributos-padronizados}

Use as compras de PJ para preencher os 6 atributos na linha de informação do jutsu. A maioria dos campos vem direto dos componentes que você comprou:

- ALCANCE — vem da compra na tabela de Alcance.
- DURAÇÃO — Instantâneo se não comprou efeito contínuo; "X PC/turno" se o efeito é mantido.
- ÁREA — vem da compra na tabela de Área.
- ATAQUE — 1d20 + perícia do Tipo (Ninjutsu, Taijutsu…), que já inclui o atributo. Jutsus de área não rolam ataque: os alvos fazem Resistência. "Automático" se você comprou "Persegue o alvo" ou se o jutsu não tem como falhar.
- RESISTÊNCIA — DT do Jutsu = 10 + bônus de Rank (E +0, D +1, C +2, B +3, A +4, S +5) + atributo-chave do lançador. O atributo do teste depende do efeito: Acrobacia contra área, FOR contra prisão e empurrão, VIG contra veneno e atordoamento, ESP contra Genjutsu.
- AÇÃO — Primária por padrão. Secundária custa +2 PJ extras. Reação custa +3 PJ. Completa libera -1 PJ.

## 20.5 Exemplos de Criação {#exemplos-de-criacao}

### Exemplo 1 — Hyousenkou no Mai (Yuki, Rank C) {#exemplo-1-hyousenkou-no-mai-yuki-rank-c}

Conceito: mil agulhas de gelo circundam alvos em área. Tipo: Ninjutsu (Hyouton). Compras de PJ:

- Dano 2d6 (3 PJ)
- Alcance Médio (2 PJ)
- Área Esfera 3m (2 PJ)
- Aplica Sangramento (2 PJ)

Total: 9 PJ → Rank C → Custo: 9 PC. Tempo de criação: 2 meses sob mestra de Kirigakure.

::jutsu{slug="hyousenkou-no-mai"}

### Exemplo 2 — Konoha Daikaiten (Taijutsu, Rank D) {#exemplo-2-konoha-daikaiten-taijutsu-rank-d}

Conceito: chute giratório de 360 graus, atinge todos ao redor. Tipo: Taijutsu — custo em PE.

- Dano 1d6 + FOR (1 PJ — o atributo é grátis em Taijutsu)
- Alcance Pessoal (0 PJ)
- Área Esfera 3m centrada em você (2 PJ)
- Empurra alvos atingidos 1m (1 PJ)

Total: 4 PJ → Rank D → Custo: 4 PE. Sem selos (Taijutsu nunca usa selos). Tempo: 1 mês de treino físico.

::jutsu{slug="konoha-daikaiten"}

### Exemplo 3 — Rasengan Sombrio (Ninjutsu, Rank A) {#exemplo-3-rasengan-sombrio-ninjutsu-rank-a}

Conceito: Rasengan modificado com chakra negro que queima espiritualmente. Tipo: Ninjutsu. Compras:

- Dano 6d8 (15 PJ)
- Alcance Toque (0 PJ)
- Drena chakra do alvo (2 PJ)
- Não pode ser copiado por Sharingan (+3 PJ)
- Causa 1d6 dano ao próprio usuário (-1 PJ)

Total: 19 PJ → Rank A → Custo: 19 PC. Sem selos custaria +2 PJ (21), mas o jogador mantém os selos de uma mão. Tempo: 1 ano de criação.

::jutsu{slug="yami-no-rasengan"}

### Exemplo 4 — Suiton: Mizurappa (Ninjutsu, Rank D) {#exemplo-4-suiton-mizurappa-ninjutsu-rank-d}

Conceito: jato de água pressurizada que empurra. Tipo: Ninjutsu. Compras:

- Dano 1d6 (1 PJ)
- Alcance Curto (1 PJ)
- Empurra alvo (1 PJ)

Total: 3 PJ → Rank D → Custo: 3 PC. Sem selos custaria +2 PJ (5 PJ, ainda Rank D, 5 PC); o jogador mantém os selos e fica em 3 PC.

::jutsu{slug="suiton-mizurappa"}

### Exemplo 5 — Shōsen Jutsu (Cura, Rank C) {#exemplo-5-shosen-jutsu-cura-rank-c}

Conceito: cura aliado com chakra médico em contato. Tipo: Ninjutsu (médico). Compras:

- Cura 3d6 PV (5 PJ — equivalente ao dano 3d6)
- Alcance Toque (0 PJ)
- Remove 1 condição negativa (3 PJ)

Total: 8 PJ → Rank C. Componente: mãos descobertas (durável, -1 PJ) → 7 PJ → Custo: 7 PC. Tempo: 2 meses sob médico Chunin.

::jutsu{slug="shosen-jutsu-2"}

## 20.6 Regras de Ouro {#regras-de-ouro}

- **Todo jutsu deve ser aprovado pelo Mestre.** As regras fornecem uma base para a criação, mas a decisão final sempre cabe ao Mestre, que é responsável por manter o equilíbrio da campanha.
- **Priorize a simplicidade.** Os Pontos de Jutsu (PJ) são uma ferramenta de orientação, não uma fórmula exata. Quando houver dúvida sobre um valor, utilize o número mais próximo que faça sentido para a mesa.
- **Efeitos puramente narrativos não possuem custo.** Elementos como deixar rastros de fogo, produzir sons característicos, alterar a aparência de uma técnica ou marcar visualmente um alvo não aumentam o custo do jutsu, desde que não concedam benefícios mecânicos.
- **O custo deve ser compatível com o personagem.** Se o custo final exceder a quantidade máxima de PC ou PE disponível, o jutsu pode existir, mas não poderá ser utilizado até que o personagem possua recursos suficientes para sustentá-lo.
- **Características extremas elevam o rank da técnica.** Grandes áreas de efeito, alcances excepcionais ou valores elevados de dano aumentam significativamente o poder de um jutsu. Ao combinar vários elementos poderosos, esteja preparado para que a técnica alcance ranks mais altos.
- **Criar jutsus com um Sensei traz vantagens.** Além dos benefícios narrativos do treinamento, jutsus desenvolvidos com a orientação de um mestre recebem uma redução de 2 PJ em seu custo de criação.

:::atencao{titulo="Quando o Mestre Diz Não"}
Se o Mestre rejeitar seu jutsu, geralmente significa: (a) está combinando atributos de Ranks diferentes; (b) está pulando trauma narrativo (jutsus únicos de Rank S podem exigir arcos de campanhas); (c) está abusando da abstração para esconder potência. Negocie: reduza o escopo, mude o tema, ajuste o custo. O sistema é colaborativo, não combativo.
:::
