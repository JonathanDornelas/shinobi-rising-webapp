### As Sete Espadas da Névoa (Shichinin Shū) {#as-sete-espadas-da-nevoa-shichinin-shu}

As lâminas mais famosas de Kirigakure (Vila Oculta da Névoa). Apenas sete shinobi ao mesmo tempo podem empunhá-las — formam o lendário grupo "Sete Espadachins Ninjas da Névoa". Ganhar uma é geralmente fruto de derrotar o portador anterior, ou de herança direta. Cada espada possui personalidade e regras próprias. Para empunhar uma dessas espadas é necessário ter qualquer nível de proficiência específica em uma delas, caso contrário não será possível utilizar a habilidade especial da mesma. Não é possível ser proficiente nessa categoria geral igual às demais, tornando essas armas mais seletas e únicas.

| Espada | Tradução | Dano | Peso | Habilidade Especial |
| - | - | - | - | - |
| Kubikiribocho | Espadão Decapitador | 2d10 | Extremo | Auto-regenera usando ferro do sangue dos inimigos: absorve sangue ao causar dano e usa esse "banco" para reparar entalhes em 1 dia. Indestrutível enquanto houver sangue armazenado. |
| Samehada | Pele de Tubarão | 2d6 | Extremo | Lâmina viva coberta de escamas. Drena 2d6 PC do alvo por acerto (transferindo para o portador). Pode "escolher" o portador — só funciona pleno para quem ela aceitar (ESP DT 18 para vincular). |
| Hiramekarei | Lâmina :sem[Cega] Gêmea | 1d10 | Extremo | Lâmina aparentemente sem fio. Portador canaliza chakra para formar lâminas etéreas (martelo, espada longa, machado), escolhendo uma propriedade especial para cada ataque. Cada forma custa 5 PC. |
| Kabutowari | Quebra-Capacete | 2d10 | Extremo | Conjunto machado + martelo gigante ligados por corrente. Ataques têm penetração massiva: ignora 5 de RD. Difícil de manejar (-2 AGI ao empunhar). |
| Nuibari | Agulha de Costura | 1d6 | Médio | Espada-agulha extremamente fina, com fio metálico ligado. Atravessa múltiplos alvos em linha (até 3) e os "costura" — ficam presos uns aos outros (FOR DT 17 para se separar). Letal para grupos. |
| Shibuki | Explosão | 1d8 | Pesado | Espada-pergaminho: cada golpe pode liberar selos explosivos pré-armados (1d10 dano de explosão). Capacidade de 5 selos — recarrega fora de combate. |
| Kiba | Presa-Trovão Gêmea | 1d8 | Médio | Par de espadas curtas eletrificadas permanentemente. Causam +1d6 dano elétrico em cada acerto. Em acerto, o alvo faz Resistência de VIG (DT 15) ou fica Paralisado por 1 turno. |

Para obter uma das Sete Espadas, o Mestre define o caminho narrativo: derrotar o portador atual em duelo, recebê-la como herança ritual, ou recuperá-la das ruínas onde foi perdida. Empunhar duas Espadas da Névoa simultaneamente é tabu (apenas Mangetsu Hozuki conseguiu na história canônica). Todas essas espadas possuem a qualidade **Lendária.**

## Qualidade das Armas {#qualidade-das-armas}

A qualidade afeta dano, acerto e propriedades. Mantenha sempre proporcional ao orçamento e à campanha.

| Qualidade | Modificadores | Notas |
| - | - | - |
| Frágil | -1 dano; mais propensa a quebrar narrativamente em situações extremas | Improvisadas, gastas |
| Comum | Sem modificador | Padrão de mercado |
| Boa | +1 dano | Bem forjada |
| Excelente | +1 dano, +1 acerto | Mestre ferreiro |
| Mestre | +2 dano, +1 acerto | Forja única |
| Lendária | +2 dano, +2 acerto, nome próprio | Herança ou item de campanha |

Quebra de armas é tratada narrativamente — o Mestre pode decidir que uma arma é destruída em circunstâncias extraordinárias (jutsu de Rank S direto, choque com KKG defensivo poderoso, etc.). Não há sistema mecânico de pontos de desgaste — armas duram enquanto fizerem sentido na história.

## Propriedades Especiais {#propriedades-especiais}

Cada arma possui ao menos uma propriedade especial. Para utilizá-las, o personagem deve possuir pelo menos 1 nível de proficiência ou especialização na arma específica, ou 2 níveis na categoria da arma para cada propriedade que desejar utilizar.

O usuário deve declarar quais propriedades especiais estarão ativas na arma, respeitando os requisitos de proficiência exigidos para cada uma delas. Após escolhidas, essas propriedades permanecem definidas até que o personagem realize um descanso longo, período necessário para se adaptar aos novos padrões e técnicas de uso da arma. As propriedades “Descartável” e “Munição” são as únicas exceções, sendo aplicadas automaticamente, sempre.

| Propriedade | Efeito |
| - | - |
| Afiada | Ignora 1 ponto de RD do alvo |
| Perfurante | Ignora 3 pontos de RD do alvo |
| Descartável | A arma é perdida após o uso (pode ser recuperada depois do combate, a critério do Mestre) |
| Munição | Precisa de munição para ser usada |
| Rajada | Pode arremessar mais de uma arma de uma vez, no mesmo alvo ou em alvos diferentes dentro do alcance; -1 no ataque por arma extra |
| Atordoante | -2 na rolagem de ataque; em acerto, o alvo faz Resistência de VIG (DT 10 + FOR do usuário) ou fica Atordoado |
| Defensiva | +1 de Defesa enquanto empunhada |
| Leve | +1 Iniciativa enquanto empunhada |
| Pesada | -1 Iniciativa enquanto empunhada; exige as duas mãos |
| Marcial | Pode usar a perícia Taijutsu na rolagem de ataque |
| Discreta | +1 em ataques furtivos e em testes para esconder a arma |
| Varredura | Ataca 2 inimigos adjacentes com a mesma rolagem; -2 contra o segundo |
| Desarmante | Em acerto, o alvo faz Resistência de FOR (DT 13 + proficiência do usuário na arma) ou é desarmado; o usuário pode pegar a arma |
| Elemental | Gastando 1 PC por ataque, causa +1d6 de dano do elemento escolhido na forja (Katon, Raiton etc.) |
| Vampírica | Uma vez por turno, ao causar dano, recupera 2 PV |
| Indestrutível | Imune a quebra, mesmo contra jutsus extremos |
| Selada | Armazena 1 jutsu do dono (Rank C ou inferior), liberado sem custo de PC uma vez por descanso longo |
| Alma Vinculada | Só funciona plenamente com o portador escolhido (outros sofrem -3 ao usá-la) |
| Versátil | Pode ser usada corpo a corpo ou arremessada |
