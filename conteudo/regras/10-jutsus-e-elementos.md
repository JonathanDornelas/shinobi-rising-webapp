## Os Cinco Elementos Básicos {#os-cinco-elementos-basicos}

Todo ninja tem afinidade natural com um elemento. Ninjas avançados podem aprender um segundo elemento (a partir do nível 5 — cap. 18) e os mais raros podem combiná-los em Kekkei Genkai elementais.

| Elemento | Forte contra | Fraco contra |
| - | - | - |
| Katon (Liberação de Fogo) | Vento, Madeira | Água |
| Suiton (Liberação de Água) | Fogo | Terra |
| Doton (Liberação de Terra) | Água | Raio |
| Raiton (Liberação de Raio) | Terra | Vento |
| Fuuton (Liberação de Vento) | Raio | Fogo |

Quando dois jutsus se chocam (por exemplo, um jutsu defensivo usado como Reação contra um ofensivo), os lançadores fazem um teste oposto de 1d20 + perícia do jutsu + bônus de Rank (E0 a S5). O lado com vantagem elemental soma +5.

## Catálogo de Jutsus {#catalogo-de-jutsus}

### Estrutura Padrão de um Jutsu {#estrutura-padrao-de-um-jutsu}

Cada jutsu listado neste livro segue uma estrutura padrão. Quando você lê uma técnica, espera encontrar os seguintes campos:

| Campo | O que significa |
| - | - |
| Nome | Nome em rōmaji e tradução |
| Origem | Elemento, clã ou categoria (Academia, Taijutsu…) |
| Rank | E (mais fraco) a S (mais poderoso) — define custo de aprendizado e nível mínimo |
| Custo | PC (ou PE, para Taijutsu e Bukijutsu) gastos ao usar; igual aos PJ do jutsu |
| Tipo | Ninjutsu, Genjutsu, Taijutsu, Bukijutsu, Fuuinjutsu ou Kugutsu |
| Alcance | Distância máxima do alvo ou da área afetada |
| Duração | Instantâneo, X turnos, sustentado (custo por turno) ou cena |
| Área | Alvo único, alvos adicionais ou forma da área |
| Ataque | Rolagem do usuário contra a Defesa (ou "—" em jutsus de área) |
| Resistência | Teste do alvo contra a DT do Jutsu, quando houver |
| Ação | Primária, Secundária, Reação ou Completa |
| Efeito | O que o jutsu faz mecanicamente — dano, condição, área etc. |

Todos os jutsus deste catálogo usam o mesmo formato de card dos clãs. Rank e custo seguem a tabela de Pontos de Jutsu (cap. 20); a última linha de cada card mostra a conta de PJ, para servir de referência na criação de técnicas.

Nível mínimo para aprender: Rank B no nível 6, Rank A no 11 e Rank S no 15 (cap. 18).

### Técnicas de Taijutsu (combate corporal) {#tecnicas-de-taijutsu-combate-corporal}

Taijutsu não usa chakra elemental: suas técnicas custam PE (estamina) e somam FOR ao dano. Abaixo, técnicas para escolha rápida na criação ou em treino.

::jutsu{slug="omote-renge"}

**Hachimon Tonkou (Liberação dos Oito Portões)**

Não é uma técnica única, mas o sistema completo dos Portões Internos. Veja capítulo 16 para abertura, custos e habilidades.

**Strong Fist (Punho Forte) — descrição narrativa, não mecânica**

Estilo predominante de Maito Gai e Rock Lee, focado em força bruta e impactos diretos. Mecanicamente, NÃO é uma proficiência — descreva o personagem como praticante de Strong Fist e use a perícia Taijutsu normalmente. As manobras icônicas (Counter Strike, Dynamic Entry, Konoha Senpuu, Omote Renge) são técnicas individuais — algumas listadas neste capítulo, outras criadas via cap. 20. Investir nelas como Proficiência específica em jutsu (ex: "Treinado em Konoha Senpuu") é o caminho mecânico.

**Gentle Fist / Juuken (Punho Suave) — descrição narrativa, exclusivo Hyuuga**

Estilo do clã Hyuuga (cap. 8.3.6). O bônus mecânico vem do clã: a habilidade Juuken (marco do nível 1) e as técnicas dos Oito Trigramas. Ataques de Juuken usam CTR no lugar de FOR. Para se especializar, treine proficiência em uma técnica concreta (ex.: Hakke Rokujūyon Shō).

## Aprender Novos Jutsus {#aprender-novos-jutsus}

| Rank | PT necessários | Tempo mínimo |
| - | - | - |
| E | 1 PT | 1 dia |
| D | 2 PT | 3 dias |
| C | 4 PT | 1 semana |
| B | 8 PT | 2 semanas |
| A | 15 PT | 1 mês |
| S | 30 PT | 3+ meses |

Nível mínimo: jutsus de Rank B exigem nível 6, Rank A exigem nível 11 e Rank S exigem nível 15 e aprovação do Mestre. Vale para jutsus aprendidos com PT, copiados ou criados.
